## Project Structure
- `Project_1_COVID19_Dashboard/`
  - `covid19_data.csv`: Synthetic dataset for COVID-19 trends, vaccinations, and mortality rates.
  - `covid_analysis.py`: Complete Python script for EDA, data cleaning, visualization, and dashboard generation.
- `Project_2_Sales_Dashboard/`
  - `sales_data.csv`: Synthetic sales dataset containing regional, customer segment, and order information.
  - `sales_analysis.py`: Python code for monthly sales trends, profit breakdown, pie chart, and segment boxplots.

---

## Requirements
Install required Python packages before running the scripts:
```bash
pip install pandas numpy matplotlib seaborn
```

## How to Run
1. **COVID-19 Analysis:**
   ```bash
   cd Project_1_COVID19_Dashboard
   python covid_analysis.py
   ```
2. **Sales Analytics Dashboard:**
   ```bash
   cd Project_2_Sales_Dashboard
   python sales_analysis.py
   ```
